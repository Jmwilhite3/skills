BOARD

Turns a business's customer reviews into the IF YOU / YOU NEED whiteboard ad.

Download BOARD

On your phone? Email it to yourself and install it on your computer.

What it does

  1. Reads the reviews and finds the six most common reasons people bought, each backed by reviews quoted word for word
  2. Writes the full 60-second ad
  3. Draws the hand-drawn board on Higgsfield and animates it with Wan 3.0
  4. Voices and captions it into a ready 9:16 clip

You'll need

  • Higgsfield connected to Claude: about 50 credits a board, quoted before anything is spent
  • Your reviews, 200 or more if you have them (a file, a paste or a link)
  • For the final cut: Claude Code on a Mac with ffmpeg and uv. claude.ai does everything up to the board video

Install it

Unzip the download first. Its README says the rest too.

Claude (web or desktop)

  1. In Settings → Capabilities, turn on Code execution and file creation.
  2. Go to Customize → Skills, click +, then Create skill → Upload a skill, and pick a7-board.zip from inside the folder.

Claude Code

  1. Copy the skill into your skills folder: cp -R a7-board/skills/a7-board ~/.claude/skills/
  2. Start a new Claude Code session.

Then type

Make a board for [business]
